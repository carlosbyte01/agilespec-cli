# Agile Refine Session

## Usage

Invoked manually with [`/agile-refine-session`](./SKILL.md) or triggered when project requirements need clarification.

## Objectives

Refine the project by analyzing the current state and identifying missing features, user stories, and dependencies. This is a collaborative process.

## Action Flow

1. **Inform**: Show a "Refine Session" banner.
2. **Current State**: Display a table with existing features, user stories, and dependencies.
3. **Collaborate**: Ask for questions or clarifications.

## Collaborative Actions

The Human (or lead architect agent) can:
- Add, remove, or modify features
- Add, remove, or modify user stories
- Add, remove, or modify dependencies

## Activation (NLP Triggers)

- "Refine the session"
- "Start the refine session"
- "Refine the project"
- "Refine the user stories"
