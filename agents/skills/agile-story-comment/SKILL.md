# Agile Story Comment

## Usage

Invoked manually with [`/agile-story-comment`](./SKILL.md) or triggered when the user wants to document feedback on a user story.

## Action Flow

1. **Add comment**: Append the comment to the user story's comments section in the correct table format.

## Activation (NLP Triggers)

- "Add a comment to story [ID]"
- "Comment on story [ID]"
- "I've added a comment to story [ID]"
- "Story [ID] has a comment"
