# Agile Feature Comment

## Usage

Invoked manually with [`/agile-feature-comment`](./SKILL.md) or triggered when the user wants to document feedback on a feature.

## Action Flow

1. **Add comment**: Append the comment to the feature file's comments section in the correct table format.

## Activation (NLP Triggers)

- "Add a comment to feature [ID]"
- "Comment on feature [ID]"
- "I've added a comment to feature [ID]"
- "Feature [ID] has a comment"
